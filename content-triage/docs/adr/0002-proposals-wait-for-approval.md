# Learn and Skill-bucket items get only a proposal; Mindset reads are written automatically

A triage run is unattended. A Learn item starts a new teach-from-source workspace, and a Skill-bucket item starts a new Claude skill that changes how Claude acts in all of AB's sessions. Both are expensive and change AB's setup. Thus a run writes only a proposal for these items, and the work starts only after AB's explicit approval. A Mindset short read is cheap and is the result itself, so the run writes it with no approval. Claude never starts a teach-from-source lesson by itself.

## Considered Options

- **Claude starts all work by itself.** Rejected: unwanted workspaces and skills would collect, and a wrong skill can change Claude's behaviour everywhere.
- **All buckets wait for approval.** Rejected: a wait for a 200-word read gives no value.
